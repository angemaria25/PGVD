📊 MODELOS ENTRENADOS
================================================================================

El sistema entrena automáticamente 4 modelos:

1. NAIVE BAYES (Multinomial)
   • Ventajas: Rápido, bueno para texto
   • Desventajas: Menos preciso
   • Tiempo: ~1 segundo

2. SVM (Support Vector Machine)
   • Ventajas: Muy preciso, robusto
   • Desventajas: Más lento
   • Tiempo: ~5 segundos
   • ⭐ GENERALMENTE EL MEJOR

3. RANDOM FOREST
   • Ventajas: Robusto, interpretable
   • Desventajas: Requiere más memoria
   • Tiempo: ~10 segundos

4. LOGISTIC REGRESSION
   • Ventajas: Rápido, interpretable
   • Desventajas: Menos preciso
   • Tiempo: ~2 segundos

El sistema selecciona automáticamente el modelo con mayor F1-Score.

================================================================================
🎓 CONCEPTOS CLAVE
================================================================================

TF-IDF (Term Frequency-Inverse Document Frequency)
   • Convierte texto en números
   • Pondera palabras por importancia
   • Reduce dimensionalidad
   • Mejora rendimiento del modelo

MATRIZ DE CONFUSIÓN
   • Muestra predicciones correctas e incorrectas
   • Identifica clases problemáticas
   • Ayuda a mejorar el modelo
   • Formato: [TP, FN; FP, TN]

MÉTRICAS
   • Accuracy: (TP+TN)/(TP+TN+FP+FN)
   • Precision: TP/(TP+FP)
   • Recall: TP/(TP+FN)
   • F1-Score: 2*(Precision*Recall)/(Precision+Recall)

VALIDACIÓN CRUZADA
   • Divide datos en múltiples folds
   • Entrena y evalúa múltiples veces
   • Reduce overfitting
   • Más confiable que train/test simple

🐛 TROUBLESHOOTING RÁPIDO
================================================================================

PROBLEMA: ModuleNotFoundError: No module named 'sklearn'
SOLUCIÓN: pip install scikit-learn

PROBLEMA: Modelo no encontrado
SOLUCIÓN: Ejecuta primero: python ml_training.py

PROBLEMA: Baja precisión del modelo
SOLUCIONES:
   • Aumentar datos de entrenamiento
   • Ajustar hiperparámetros
   • Usar feature engineering más avanzado
   • Probar con diferentes modelos
   • Limpiar datos de entrada

PROBLEMA: Kafka connection refused
SOLUCIÓN: Verifica que Kafka esté corriendo: docker-compose ps

PROBLEMA: HDFS connection refused
SOLUCIÓN: Verifica que HDFS esté disponible: hdfs dfs -ls /

PROBLEMA: Baja confianza en predicciones
SOLUCIONES:
   • Entrenar con más datos
   • Usar modelos más complejos
   • Mejorar feature engineering
   • Ajustar threshold de confianza
